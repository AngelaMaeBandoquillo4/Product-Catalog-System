http://localhost/product_catalog/user_view.php

Features:
- Admin login and logout
- Dashboard statistics
- Product add, view, edit, delete
- Category add, edit, delete
- Product search
- Category filter
- Optional image upload
- Optional image URL
- Product image preview from uploaded files or web URLs
- Public user catalog without login
- Responsive teal and mint interface

Database:
product_catalog

The application automatically creates the required users, categories, and tables when db.php is loaded. The database.sql file is also included for phpMyAdmin import.
